# Quoter — BRL → Fiat

Web app to quote and confirm BRL purchases of EUR, ARS, COP, MXN, and ZAR using USDT as the bridge currency.

## Layout

- `api/` — planned HTTP API.
- `web/` — planned Vite + React client.

## Prerequisites

- Node.js 20+
- npm
